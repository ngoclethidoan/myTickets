Fonts used by the site, kept here so the pages look the same without an internet connection.

  Be Vietnam Pro          body text (covers Vietnamese)
  Big Shoulders Display   headings and numbers

Both are open-source fonts under the SIL Open Font License, Version 1.1
(https://openfontlicense.org). The .woff2 files were taken unchanged from the npm packages
@fontsource/be-vietnam-pro and @fontsource-variable/big-shoulders-display.
